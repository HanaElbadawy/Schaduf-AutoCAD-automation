# Stage 01 — Landscape Render to AutoCAD 2D

## Objective

Convert a provided landscape design render or top-view image into a complete, editable 2D AutoCAD drawing while following the official SITES CAD standards.

## Instructions

### 1. Understand the Standards First
- Read the installed SITES AutoCAD Standards skill.
- Review all relevant reference documents before creating geometry.
- Follow documented naming conventions, layer rules, block standards, units, and drawing requirements.
- Do not invent undocumented standards.
- Clearly distinguish official standards from provisional decisions.

### 2. Analyze the Input Image
- Identify all visible landscape elements, including:
  - Site boundaries
  - Buildings and structures
  - Roads and parking areas
  - Pedestrian pathways
  - Hardscape areas
  - Planting areas
  - Trees and vegetation
  - Landscape furniture
  - Water features
- Identify the approximate position, proportions, and relationships between elements.
- Identify missing information, unclear geometry, and assumptions.
- Do not claim accurate dimensions if the image has no scale reference.

### 3. Prepare the AutoCAD Drawing
- Inspect the active drawing before making changes.
- Verify drawing units and coordinate system.
- Set units according to the documented SITES requirements.
- Create and organize layers using official naming conventions.
- Apply documented colors and lineweights.
- Use blocks where appropriate and follow documented block naming rules.
- Keep block geometry organized according to the standards.
